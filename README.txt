Zauber auf Papier - statische Landingpage

Zum Starten:
1. Den Ordner "Zauber-auf-Papier-Landingpage" öffnen.
2. Die Datei "index.html" doppelklicken.

Die Seite läuft direkt im Browser. Es ist kein npm, Next.js oder Server nötig.

Unterseiten:
- Der Ordner "seiten" enthält einzelne HTML-Seiten für Menü, Über mich, Impressum, Datenschutz und Kontakt.
- Die Startseite verlinkt auf diese Unterseiten.

Bilder austauschen:
- Neue Bilder in den Ordner "images" legen.
- In "index.html" den jeweiligen Dateinamen im src="images/..." austauschen.

Links austauschen:
- In "index.html" bei den Buttons href="#" durch deinen echten Link ersetzen.
